This is a project for Terra's 2 week.

Since the theme for this week was something antique, I decided to do an operational system inspired by classic DOS computers and early command-line interfaces.

The DOS runs on Github Pages and it includes its own virtual file system where users can navegate through directories, create and remove folders, create and read text files, rename and delete files, and run executable programs. The file system is saved using browser local storage, allowing changes made by the user to remain even after refreshing or reopening LunaDOS.

LunaDOS also has its own executable program (.EXE), The first executable programs is the classic SNAKE game a playable terminal-based version of Snake located inside the GAMES directory. The game includes directional movement, randomly generated food, score tracking, snake growth, collision detection, game-over and retry functionality, and the ability to exit back into LunaDOS.

The current available commands for the LunaDOS are the following:

*HELP, as its name sugguest is the list of all available commands.
*VER, although symbolic, shows the version of the DOS.
*ECHO, displays text on the screen.
*CLS, cleans the screen.
*DIR, shows the directory and its files.
*CD, is used to navigate through the folders and files.
*TYPE, is used yo write and create files.
*MKDIR, makes a new directory.
*RMDIR, deletes an empty directory.
*DEL, deletes files.
*REN, renames files or directorys.
